Voz sintetica local del canal: Kokoro-82M (probada en el video 001).

Que hay aqui
.venv\       entorno de Python solo para Kokoro (no se sube al repositorio)
modelos\     kokoro-v1.0.onnx (325 MB) y voices-v1.0.bin (28 MB) (no se suben)

Como se usa
herramientas\.venv\Scripts\python.exe herramientas\producir.py voz NNN
(corre voz_kokoro.py con este entorno y sigue con ritmo, tiempos y subtitulos)

Instalacion en un equipo nuevo, desde la raiz del repositorio
python -m venv herramientas\kokoro\.venv
herramientas\kokoro\.venv\Scripts\python.exe -m pip install kokoro-onnx soundfile
curl.exe -sSL --fail --create-dirs -o herramientas\kokoro\modelos\kokoro-v1.0.onnx https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/kokoro-v1.0.onnx
curl.exe -sSL --fail -o herramientas\kokoro\modelos\voices-v1.0.bin https://github.com/thewh1teagle/kokoro-onnx/releases/download/model-files-v1.0/voices-v1.0.bin
